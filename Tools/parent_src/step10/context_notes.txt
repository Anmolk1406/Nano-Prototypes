## M-Checkbox
**Node ID:** 724:11403

Selection control for toggling items on or off. Use for multi-select lists and independent binary options. Usage: - Use for multi-select lists, consent/terms acceptance, and filter groups where multiple options can be active at once. - Don't use for mutually exclusive choices (use radio) or for inline on/off settings in a row (use M-Switch). - Always pair with a label — the box alone is not a sufficient tap target. Sizes: H24 default; H20 for dense lists; H16 for compact tables only (avoid on touch). States: Default, Selected, Disabled. Prefer hiding over disabling when the option will never become available in context.

## M-SecondaryNeutralButton
**Node ID:** 712:12880

A secondary call-to-action button. Lower visual weight than the primary — pair with a primary button when you need a supportive or alternative action (e.g. "Cancel" next to "Save", "Shop more" next to "Add to cart"). Usage: - Use as the supporting action when a primary CTA is also present. - Don't use as the only action on a screen — promote to M-Button/Primary instead. - Keep labels short and verb-first ("Cancel", "Edit", "Shop more"). - Use Loader state on submit/async actions; the spinner replaces the label and icons while preserving the button's footprint. - Toggle Show icon left / Show icon right to add directional or supporting glyphs from M-Icon/\*. Sizes (height): H56, H52, H44, H36. States: Default, Pressed, Loader, Disabled.

## M-NeutralButton
**Node ID:** 727:2

Neutral, dark-inverted CTA. Visually quieter than M-Button/Primary — use when multiple actions coexist on light surfaces (e.g., "Schedule", "Select location", "Login/Sign up") or when the page already has a primary action elsewhere. 20 variants: 5 sizes × 4 states. Usage: - Use for secondary-weight CTAs on light backgrounds where a high-emphasis navy/near-black button reads better than action-blue. - Don't stack two Neutral buttons next to each other — pair with M-Button/Secondary (outline) for the adjacent action. - Don't use on dark/inverted surfaces — the inverted fills will disappear; use M-Button/Secondary or a light-surface variant instead. - H56 for main sheet/form CTAs; H52/H44 for inline actions; H36 for rows/tables; H32 for dense toolbars and compact contexts. Notes: - Loader state keeps label & icons at opacity 0 so the button doesn't reflow. - Corner smoothing is 60% on all sizes — don't rebuild with plain rounded rectangles. - Disabled shares the same muted-on-subtle-surface pattern as Primary.
