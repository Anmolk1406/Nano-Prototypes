## M-PrimaryButton
**Node ID:** 712:12592

High-emphasis CTA for primary actions on a page or flow. Filled blue surface with white label; supports optional left/right icons, a loading state, and a disabled state. Usage: - Use for the single most important action on a screen (Save, Continue, Checkout). - Only one primary button per context — pair secondary actions with M-Button/Secondary. - Choose size from page density: H56 for main CTAs in bottom sheets and full-width forms, H52/H44 for inline content actions, H36 for compact rows and tables. - Use Loader state while an action is in flight; the button stays the same size to prevent layout shift. - Disabled state signals the action is unavailable — prefer hiding the button if the action will never be available in this context.

## M-SecondaryButton
**Node ID:** 386:936

A secondary call-to-action button. Lower visual weight than the primary — pair with a primary button when you need a supportive or alternative action (e.g. "Cancel" next to "Save", "Shop more" next to "Add to cart"). Usage: - Use as the supporting action when a primary CTA is also present. - Don't use as the only action on a screen — promote to M-Button/Primary instead. - Keep labels short and verb-first ("Cancel", "Edit", "Shop more"). - Use Loader state on submit/async actions; the spinner replaces the label and icons while preserving the button's footprint. - Toggle Show icon left / Show icon right to add directional or supporting glyphs from M-Icon/\*. Sizes (height): H56, H52, H44, H36. States: Default, Pressed, Loader, Disabled.
