## M-NeutralButton
**Node ID:** 727:2

Neutral, dark-inverted CTA. Visually quieter than M-Button/Primary — use when multiple actions coexist on light surfaces (e.g., "Schedule", "Select location", "Login/Sign up") or when the page already has a primary action elsewhere. 20 variants: 5 sizes × 4 states. Usage: - Use for secondary-weight CTAs on light backgrounds where a high-emphasis navy/near-black button reads better than action-blue. - Don't stack two Neutral buttons next to each other — pair with M-Button/Secondary (outline) for the adjacent action. - Don't use on dark/inverted surfaces — the inverted fills will disappear; use M-Button/Secondary or a light-surface variant instead. - H56 for main sheet/form CTAs; H52/H44 for inline actions; H36 for rows/tables; H32 for dense toolbars and compact contexts.
