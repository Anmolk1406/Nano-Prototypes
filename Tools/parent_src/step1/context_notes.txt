## M-Radio
**Node ID:** 993:39826

Selection control for picking exactly one option from a mutually exclusive set. Use when only a single choice is valid within a group. Usage: - Use for mutually exclusive choices in forms, settings, and short option lists (e.g. shipping speed, payment method). - Don't use for multi-select (use M-Checkbox), for immediate action (use a button), or for more than ~5 options (use a dropdown/select). - Always render in a group of two or more — a lone radio is never correct. Always pair with a label; the dot alone is not a sufficient tap target. Sizes: H24 default; H20 for dense lists and option groups; H16 for compact tables only (avoid on touch). States: Default, Selected, Disabled. Prefer hiding over disabling when the option will never become available in context.

## M-NeutralButton
**Node ID:** 434:6632

Neutral, dark-inverted CTA. Visually quieter than M-Button/Primary — use when multiple actions coexist on light surfaces (e.g., "Schedule", "Select location", "Login/Sign up") or when the page already has a primary action elsewhere. 20 variants: 5 sizes × 4 states. Usage: - Use for secondary-weight CTAs on light backgrounds where a high-emphasis navy/near-black button reads better than action-blue. - Don't stack two Neutral buttons next to each other — pair with M-Button/Secondary (outline) for the adjacent action. - Don't use on dark/inverted surfaces — the inverted fills will disappear; use M-Button/Secondary or a light-surface variant instead. - H56 for main sheet/form CTAs; H52/H44 for inline actions; H36 for rows/tables; H32 for dense toolbars and compact contexts. Notes: - Loader state keeps label & icons at opacity 0 so the button doesn't reflow. - Corner smoothing is 60% on all sizes — don't rebuild with plain rounded rectangles. - Disabled shares the same muted-on-subtle-surface pattern as Primary.
